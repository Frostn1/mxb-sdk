# mxb-sdk changelog

## Game SDK 1.2.0

- Added the live feed, derived events, laps, and online fairness filtering.
- Added schema version 1, the compatibility handshake, capabilities, and generated types.
- Added HTTP, WebSocket, extension, and MCP access.
- Removed: game actions. The packages were never published, so they are removed before the first release instead of deprecated.

## Developer packages 0.1.0

- Added `mxb-core`, `mxb-game`, `mxb-extensions`, `mxb-plugins`, `mxb-mcp`, and `mxb-sdk`.
- Added matching npm packages and the grouped `mxb` CLI.
