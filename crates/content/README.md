# mxb-content

Headless readers for MX Bikes content: plain `.pkz` packages (zip), track descriptors and the
terrain headers `mxb-core` needs to identify and verify mods. No network, no image decoding, and
no support for protected packages: those are reported as opaque and never opened.

Part of [mxb-sdk](https://github.com/Frostn1/mxb-sdk). MIT licensed.
